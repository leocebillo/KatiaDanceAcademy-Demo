Baila con Katia Dance Academy - website files

Open index.html in a browser to preview. To publish, upload this whole folder to any static host (Netlify, GitHub Pages, Cloudflare Pages, or your domain host).

Files
  index.html, classes.html, about.html, pricing.html, contact.html
  css/styles.css   all styling and brand colors (see :root at the top)
  js/main.js       banner, pricing picker, demo checkout, photo gallery
  images/          neon-sign.jpg (logo)

To do before launch
  1. Replace placeholders: address, phone, social handles, Katia's bio, stats, prices, class times.
  2. Photos: put class photos in images/ and fill the PHOTOS list at the top of the gallery code in js/main.js, e.g. {src:'images/salsa.jpg',cap:'Salsa night'}
  3. Payments: the checkout is a demo and charges nothing. Replace it with a Stripe or Square payment link or checkout. Do not collect card numbers with a custom form.
